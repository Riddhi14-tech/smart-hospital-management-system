# Smart Hospital Management & Emergency Care System

## Project Overview
A console-based hospital management system developed using C++17 as part of our Project-Based Learning (PBL) project.

## Team Name
ctrl+creators

## Project Modules
- Patient and Clinical Management
- Doctor and Appointment Management
- Emergency Management
- Bed Management
- Main Menu Integration

## Concepts Used
- C/C++ programming fundamentals
- Structures, functions, arrays and loops
- Object-Oriented Programming (classes, objects, encapsulation and inheritance)
- Searching and linked-list traversal
- Queue and priority-based insertion
- Pointers and dynamic memory allocation

## Technologies
- Language: C++17
- Interface: Console-based
- Data Structures: Manually implemented; no STL containers

## How to Compile and Run

Compile using a C++17 compiler:

```bash
g++ -std=c++17 main.cpp -o hospital
```

Run on Linux/macOS:

```bash
./hospital
```

On Windows, run `hospital.exe`.

## Current Limitations
- Bed capacity is currently limited to three beds.
- Patient data is not permanently saved after the program exits.
- A bed release/discharge feature can be added in a future version.
